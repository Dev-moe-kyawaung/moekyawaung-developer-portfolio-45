## ✨ Overview

A fast, single-file, production-ready developer portfolio built with a neon **cyberpunk aesthetic** — glowing accents, smooth scroll-triggered animations, and a typewriter-style intro. Built for performance: the entire app is bundled into a single HTML file via `vite-plugin-singlefile`, making it trivially easy to deploy anywhere.

**🔗 Live production build:** **[01a04ff1-4207-704a-b042-ac78b44d1695.arena.site](https://01a04ff1-4207-704a-b042-ac78b44d1695.arena.site/)**

---

## 🚀 Features

- 🎨 **Cyberpunk visual theme** — neon glow accents, dark base palette, glitch/scan-line style detailing
- 🎬 **Premium scroll animations** — sections animate in via `react-intersection-observer`
- ⌨️ **Typewriter hero text** — animated role/title cycling powered by `react-type-animation`
- ⚡ **Blazing-fast build** — Vite 7 + single-file bundling for one-file, zero-config deployment
- 🎯 **Type-safe** — written in TypeScript across the board
- 🧩 **Utility-first styling** — Tailwind CSS 4 with `tailwind-merge` and `clsx` for clean conditional classes
- 🖼️ **Icon system** — `react-icons` for scalable, consistent iconography
- 📱 **Fully responsive** — optimized for mobile, tablet, and desktop viewports

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- npm (bundled with Node)

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-45.git
cd moekyawaung-developer-portfolio-45

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Runs the app in development mode with hot reload. Open the printed local URL in your browser.

### Production Build

```bash
npm run build
```

Bundles the app into a single, self-contained `index.html` (via `vite-plugin-singlefile`) inside `dist/` — ready to deploy to any static host.

### Preview Production Build

```bash
npm run preview
```

## 🌐 Deployment

Because the production build compiles to a single HTML file, it can be deployed anywhere that serves static files:

- **GitHub Pages**
- **Vercel / Netlify**
- **Any static file host** — just upload the contents of `dist/`
